# 모두투어 상품 임포트·후편집 가이드

모두투어 등 외부 상품을 가져온 뒤, 관리자에서 내용을 보완하는 흐름을 정리합니다.

## 가격 입력 정책

모두투어 상품은 **출발일별 가격이 다르므로**, 수입(import) 시 가격은 **참고용**으로만 사용합니다.

관리자에서 아래 중 하나로 운영합니다.

1. **기본 가격(`price`)만 사용** — 카드·상세의 대표가·fallback·SEO에 반영됩니다.
2. **가격 구간(비수기 / 주말 / 성수기) 입력** — 상세 등에서 구간별 안내와 함께 쓰입니다.

**모든 날짜 가격을 입력할 필요는 없습니다.** 대표적인 구간만 두고, 세부 요금은 상담으로 안내하는 것을 원칙으로 합니다.

가격 구간은 익스텐션·자동 임포트로 채우지 않으며, 운영자가 관리자 **기본 정보**에서 직접 입력합니다.
