# 배포 전 QA 체크리스트 (관리자 상품)

배포 직전 또는 회귀 점검 시 아래 항목을 확인하세요.

## 생성

- [ ] 최소 필드(상품명, 설명, 대표 이미지)만으로 상품 등록 가능
- [ ] Modetour import 후 생성 가능
- [ ] 생성 후 목록에 즉시 반영
- [ ] 생성 후 preview / 공개 상세 진입 정상

## 수정

- [ ] 목록에서 편집 진입 시 해당 상품 데이터 로드
- [ ] 텍스트만 수정 후 저장 → 재진입 시 동일 내용
- [ ] 이미지 재배치 후 저장 → 일정/이벤트 이미지 순서 유지
- [ ] 수정 후 목록·preview·공개 상세 반영

## Validation

- [ ] 같은 이벤트 내 이미지 중복 시 저장 차단, 메시지 명확
- [ ] 이벤트와 미할당 풀에 동일 이미지 동시 배치 시 저장 차단
- [ ] 빈 이벤트·미할당 이미지 남음 → 경고만 표시, 저장 가능

## 목록

- [ ] 검색(키워드) 정상
- [ ] 노출/비노출·예약상태 필터 정상
- [ ] 정렬(최근 수정순, 제목순 등) 정상
- [ ] 조회 실패 시 에러 문구 + "다시 불러오기" 동작
- [ ] 등록 상품 없음 / 검색 결과 없음 빈 상태 문구 정상

## 상세·Preview

- [ ] 이미지 많은 상품: 대표 이미지·이벤트 이미지 순서 정상
- [ ] 이미지 없는 상품: placeholder, 레이아웃 깨짐 없음
- [ ] 일정 없음: "일정 정보 준비 중입니다." 등 fallback
- [ ] 모바일 폭에서 레이아웃 깨짐 없음

## 오류 처리

- [ ] 저장 중 버튼 비활성화("저장 중..."), 연속 클릭 방지
- [ ] 저장 실패 시 서버 메시지 노출, 편집 내용 유지
- [ ] 잘못된 상품 ID 접근 시 404/fallback
- [ ] 비공개 상품 공개 상세 접근 시 404

## 이미지 편집 회귀

- [ ] event.images 배열 순서 = 저장/표시 순서 (첫 번째 = 대표)
- [ ] 드래그로 순서 변경 후 저장 → 재진입 시 동일 순서
